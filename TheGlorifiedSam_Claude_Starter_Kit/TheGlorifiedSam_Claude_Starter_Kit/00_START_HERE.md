# The Glorified Sam: Claude Starter Kit (free)

This is the setup I use to run my content with Claude: edits, clips, research and daily routines, without staring at a timeline all night.

This kit gets you from zero to "Claude is doing real work for me" in about 30 minutes.

## What's inside
| File | What it gives you |
|---|---|
| `01_SETUP.md` | Install Claude Code and the free tools, step by step |
| `02_FREE_SKILLS.md` | The free skill packs I actually use, and how to install them |
| `03_FREE_RESOURCES.md` | Music, sound effects, fonts and tools you're allowed to use |
| `templates/CLAUDE.md` | A starter "brain file" so Claude knows you, your channel and your rules |
| `templates/DAILY_ROUTINE.md` | A ready-made daily routine you can schedule |
| `prompts/` | Copy-paste prompts for clipping, captions, research and planning |
| `04_RULES_THAT_KEEP_YOU_SAFE.md` | How not to get banned, claimed or scammed |
| `05_WANT_MORE.md` | What I didn't put in here |

## The 3 rules that make Claude actually useful
1. **Give it a brain file.** Claude only knows what you tell it. `templates/CLAUDE.md` is the cheat code.
2. **Give it skills.** Skills are instruction packs that turn Claude into a specialist: motion graphics, sound design, cut-outs.
3. **Give it routines.** Once something works, schedule it, so Claude runs it daily while you create.

Start with `01_SETUP.md`.
